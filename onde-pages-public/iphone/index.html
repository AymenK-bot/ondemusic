Installer Onde sur iPhone

Ouvre cette adresse dans Safari, puis :

  1. Appuie sur Partager — l’icône avec une flèche vers le haut. Selon ta version d’iOS, elle peut être dans le menu du navigateur.
  2. Choisis Sur l’écran d’accueil. Fais défiler les options si nécessaire.
  3. Si l’option est proposée, garde Ouvrir comme app activé, puis appuie sur Ajouter.

Ouvre ensuite Onde avec sa nouvelle icône.

L’ajout n’est pas automatique. Internet reste nécessaire ; la lecture utilise la vidéo YouTube. Le fonctionnement en arrière-plan ou écran éteint n’est pas garanti.
